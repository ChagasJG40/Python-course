# Python Course — Estudos e exercícios

Repositório de estudos com exercícios práticos de Python organizados por aulas e desafios. Os arquivos cobrem diferentes etapas de aprendizagem e podem ser executados individualmente.

## Como executar

1. Instale o Python 3.
2. Clone ou baixe este repositório.
3. Execute um exercício pelo terminal, por exemplo:

```bash
python "Exercício 01"
```

Alguns arquivos pedem dados pelo terminal. Consulte o conteúdo do exercício para entender as entradas esperadas.

## Estrutura

Os exemplos estão identificados principalmente por aula ou número do exercício. Cada arquivo deve ser tratado como um exercício independente, não como parte de uma aplicação única.

## Objetivo

Documentar a prática contínua de lógica de programação e fundamentos de Python. O material é de estudo e pode conter exercícios em diferentes estágios de desenvolvimento.
